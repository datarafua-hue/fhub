# 🚀 Автоматический деплой на Vercel

Настроено 3 способа деплоя изменений на Vercel:

---

## 1️⃣ Быстрый деплой (одна команда)

Вместо трех команд (`git add`, `git commit`, `git push`), используйте одну:

```bash
npm run deploy
```

Это автоматически:
- ✅ Добавит все изменения
- ✅ Сделает коммит с сообщением "Update content"
- ✅ Запушит на GitHub
- ✅ Vercel автоматически задеплоит

---

## 2️⃣ Деплой с кастомным сообщением

Если хотите указать своё сообщение:

```bash
npm run deploy:msg
```

Скрипт спросит сообщение, и вы можете ввести что угодно:
```
📝 Enter commit message: Обновил статью про петли CEAM
```

---

## 3️⃣ Автоматический деплой при сохранении файлов ⭐

**Самый удобный способ!** Запустите один раз:

```bash
npm run watch
```

Теперь:
- 📝 Редактируете файл в Cursor
- 💾 Сохраняете (Cmd+S / Ctrl+S)
- ⏱️ Через 3 секунды изменения **автоматически** пушатся на GitHub
- 🚀 Vercel автоматически обновляет сайт

### Что отслеживается:

- `src/content/posts/` - статьи (markdown файлы)
- `src/pages/` - страницы
- `src/components/` - компоненты

### Как использовать:

1. Откройте терминал
2. Запустите: `npm run watch`
3. Оставьте терминал открытым
4. Работайте как обычно в Cursor
5. Все сохранения будут автоматически деплоиться!

### Чтобы остановить:

Нажмите `Ctrl+C` в терминале где запущен `npm run watch`

---

## ⚙️ Как отключить автодеплой

### Временно:
Просто не запускайте `npm run watch` и используйте обычный `git push` вручную.

### Полностью:
Если хотите чтобы Vercel НЕ деплоил автоматически при push:
1. Откройте [Vercel Dashboard](https://vercel.com/dashboard)
2. Выберите проект **fhub**
3. Settings → Git
4. Отключите "Automatically deploy from main branch"

Тогда деплой будет только ручной через Vercel Dashboard.

---

## 📊 Отслеживание деплоя

После каждого push смотрите прогресс:
- [Vercel Dashboard](https://vercel.com/dashboard)
- Вкладка **Deployments**
- Деплой занимает ~2-3 минуты

---

## 💡 Рекомендации

**Для повседневной работы:**
```bash
npm run watch    # ← Запустите и забудьте!
```

**Для важных изменений:**
```bash
npm run deploy:msg
# Введите понятное сообщение: "Добавил новую категорию петель"
```

**Для быстрых фиксов:**
```bash
npm run deploy    # ← Одна команда вместо трех
```
